# Bazaar Lane – Online Shopping Website

Bazaar Lane is a simple online shopping website built using HTML, CSS, and JavaScript.

## Features
- Product categories: Electronics, Fashion, Beauty, Sports, Books, and Home & Kitchen.
- Search and sort products by price.
- Add products to cart and manage quantities.
- Display product prices, ratings, and discounts.
- Responsive design for different screen sizes.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open `bazaar-lane-single-file.html` in your web browser.
