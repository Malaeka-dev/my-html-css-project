# Bazaar Lane – Online Shopping Website

## Mere Project Ke Bare Mein

Bazaar Lane aik simple online shopping website hai jo maine HTML, CSS aur JavaScript ka use karke banayi hai. Is project ko banane ka main purpose web development ki practice karna aur samajhna tha ke aik online shopping website kis tarah kaam karti hai.

Maine website mein different product categories add ki hain taake users asani se apni pasand ke products dekh saken. Website ka design simple aur user-friendly rakha hai, jis se products explore karna, search karna aur shopping cart manage karna asan hota hai.

## Project Ki Main Features

- **Different Product Categories:** Website mein Electronics, Fashion, Beauty, Sports, Books aur Home & Kitchen ki categories shamil hain, taake products ko different sections mein organize kiya ja sake.

- **Product Search:** Search feature ki madad se users apni pasand ka product naam likh kar dhoond sakte hain.

- **Product Sorting:** Users products ko price ke hisaab se sort kar sakte hain, jis se different prices wale products compare karna asan hota hai.

- **Shopping Cart:** Users products ko cart mein add kar sakte hain aur apni zaroorat ke mutabiq product quantities manage kar sakte hain.

- **Product Information:** Products ke sath unki prices, ratings aur discount information display hoti hai, taake users ko products ke bare mein basic details mil saken.

- **Responsive Design:** Website ka layout different screen sizes ke liye design kiya gaya hai, taake website ko different devices par use karna asan ho.

- **Simple User Interface:** Maine website ka interface simple aur attractive rakhne ki koshish ki hai, taake users easily different sections aur products ko explore kar saken.

## Technologies Used

- **HTML:** Website ka basic structure banane aur different elements ko arrange karne ke liye use kiya.
- **CSS:** Website ki styling, colors, layout aur overall appearance ko improve karne ke liye use kiya.
- **JavaScript:** Website mein interactive features, jaise product search, sorting aur shopping cart functionality add karne ke liye use kiya.

## Project Banane Se Maine Kya Seekha?

Is project par kaam karte hue maine HTML, CSS aur JavaScript ko practically use karne ki practice ki. Mujhe samajhne ka mauqa mila ke website ka structure kaise banaya jata hai, usay CSS se style kaise kiya jata hai aur JavaScript ki madad se interactive features kaise add kiye jate hain.

Iske ilawa maine product categories ko organize karna, search aur sorting features par kaam karna aur shopping cart ki functionality implement karna bhi practice kiya. Ye project mere liye web development concepts ko practically samajhne aur apni skills improve karne ka aik acha experience tha.
